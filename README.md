# Infografía personal | cherylcann

Código fuente de una versión de mi infografía y portafolio personal, donde comparto información sobre mí, mis conocimientos de programación y algunos de mis proyectos.

## Tecnologías

- HTML, CSS y JavaScript
- Node.js y Express
- EJS para reutilizar partes de las páginas

## Ejecutar en local

Necesitas tener instalado Node.js.

```bash
npm install
npm start
```

Abre `http://localhost:3000` en tu navegador.

Para desarrollar con reinicio automático:

```bash
npm run dev
```

## Estructura

- `public/css/`: estilos
- `public/js/`: scripts del navegador
- `views/`: páginas HTML y componentes compartidos
- `routes/`: rutas de Express
- `index.js`: configuración del servidor
