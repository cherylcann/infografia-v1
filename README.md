## 💡 Sobre el proyecto

**Infografía V1** forma parte de mi recorrido aprendiendo desarrollo web. La idea fue construir un espacio propio en Internet para presentarme, compartir mis intereses en la programación y mostrar algunos de mis proyectos.

Más que un producto terminado, este repositorio conserva una etapa de aprendizaje: las decisiones de diseño, la organización del código y las funcionalidades que fui incorporando con los conocimientos que tenía en ese momento.

## ✨ ¿Qué incluye?

- **Inicio:** una presentación personal con elementos visuales e interacciones.
- **Conóceme:** información sobre mí y mi relación con la programación.
- **Proyectos:** una sección para mostrar trabajos y experimentos.
- **Diseño adaptable:** estilos y scripts para diferentes tamaños de pantalla.
- **Componentes reutilizables:** elementos compartidos entre páginas, como la navegación.

## 🚀 Ejecutar localmente

Necesitas tener instalados **Node.js** y **npm**.

**1. Clona el repositorio:**

```bash
git clone https://github.com/cherylcann/infografia-v1.git
```

**2. Entra a la carpeta:**

```bash
cd infografia-v1
```

**3. Instala las dependencias:**

```bash
npm install
```

**4. Inicia el servidor:**

```bash
npm start
```

**5. Abre en tu navegador:**

```text
http://localhost:3000
```

Para iniciar el proyecto en modo desarrollo, con reinicio automático al guardar cambios:

```bash
npm run dev
```

> [!NOTE]
> El proyecto utiliza Express y EJS, por lo que no basta con abrir los archivos HTML directamente: debes iniciar el servidor de Node.js.
